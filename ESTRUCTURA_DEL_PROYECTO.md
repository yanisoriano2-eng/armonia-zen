## 🔧 Cómo Personalizar

### Cambiar Colores
Edita `css/style.css` línea 8-14:
```css
:root {
    --color-dark-green: #17281F;  /* Cambia aquí */
    --color-gold: #C9B56F;        /* O aquí */
}
```

### Agregar Productos
Edita `js/catalogo.js` array `products`:
```javascript
{
    id: 21,
    name: 'Nuevo Producto',
    category: 'piedras',
    price: 25000,
    description: 'Descripción',
    image: 'gradient(...)'
}
```

### Cambiar Número WhatsApp
Busca y reemplaza en todos los archivos:
`5491234567890` → Tu número real

### Modificar Contenido
Todos los textos están en HTML, edita directamente en los archivos `.html`.
